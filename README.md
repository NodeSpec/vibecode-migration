# Split the bill
A one-page calculator: enter a bill total, a tip percentage and a number of people to see what each person pays.
Built with Vite, React and TypeScript; the maths lives in one pure function in `src/split.ts`.
Run it: `nvm use && npm ci && npm run dev`, then open the local URL it prints.
Check it: `npm run lint`, `npm run typecheck`, `npm test` and `npm run build` (output goes to `dist/`).
